# ビューティープロ 広告効果ダッシュボード

ドッグ／キャットを切り替えて、サマリー・週ごと・日別推移を見るダッシュボード。パスワードが必要です。

## 仕組み
- `index.html` … 画面（HTML/CSS/JS 1枚）。パスワード入力 → ブラウザ内で復号して表示。
- `data/data.enc.js` … 暗号化したデータ（AES-GCM／PBKDF2）。パスワードがないと中身は読めない。
- 平文のデータ・パスワード・作成スクリプトはこのリポジトリに含めない（ローカルのみ）。

## 更新（ローカルのみ）
1. レポートシートを最新にする。
2. ローカルの `build_data.py` の数字を直して `python3 build_data.py` を実行 → `data/data.enc.js` が作り直される（実行時にサマリーとの突き合わせあり）。
3. `git add data/data.enc.js && git commit && git push`
